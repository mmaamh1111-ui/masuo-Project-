# 🏷️ Adidas Sales Analysis Dashboard

## 📊 Project Overview
This project is a professional data analysis dashboard built to analyze Adidas sales performance across multiple dimensions.  
It focuses on understanding sales trends, product performance, regional insights, and overall business profitability using key KPIs and visual analytics.

---

## 🎯 Project Objectives
- Analyze overall Adidas sales performance  
- Identify top-performing products and retailers  
- Track monthly sales trends and seasonality  
- Evaluate regional sales distribution  
- Measure profitability and revenue efficiency  
- Support data-driven business decisions  

---

## 📈 Key Performance Indicators (KPIs)
- Average Order Value  
- Total Units Sold  
- Total Profit  
- Total Sales  
- Total Sales by Retailer  
- Total Sales by Product  
- Total Sales by Region  
- Total Sales by Month  

---

## 🛠️ Tools & Technologies
- Power BI / Tableau  
- Microsoft Excel  
- Data Cleaning & Transformation  
- Data Visualization Techniques
